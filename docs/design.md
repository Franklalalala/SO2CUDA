# 设计

包分为三个层次：张量与布局接口、自动微分及分组 GEMM 编排、CUDA/C++ 原生算子。包不导入 DeePTB，也不创建模型参数。

一个 SO(2) 层的计算是一次块布局 sandwich：通道主序的 CUDA kernel 把每条边的输入旋入每个 m 一块的缓冲（m>0 块每行为 `[x_{-m} | x_{+m}]`），每块一次 GEMM（块复数权重 `[[A,-B],[B,A]]`，m=0 块用实权重与 bias），再从各块旋回并写出特征；反向手写，前置／后置径向权重与按边门控在块上或旋转 kernel 内完成。dense 接口默认保留调用方的 m=0 参考计算、只返回 m>0 贡献，`include_m0=True` 时 m=0 进入同一次 sandwich；按图分组的 dense 层与激活空间 top-k 路由把块行按组（专家）排序，每块一次 cuBLAS 分组 GEMM，按槽门控求和。

CPU 或不受支持的数学条件由模型侧参考实现处理。发生原生执行错误时不会吞掉异常重试其他数学路线。
